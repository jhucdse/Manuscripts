This repository includes codes for a paper that used TriNetX data.

The folder titled "2025_JAMA-Surg_Kim" contains SAS and R Markdown codes written by Minji Kim (ScM, 2025) for an analysis characterizing the use and factors associated with GLP-1 initiation among U.S. adults undergoing bariatric surgery (PubMed link: https://pubmed.ncbi.nlm.nih.gov/40548761/).

Kim M, Schweitzer MA, Kim JS, Alexander GC, Mehta HB. Use of Glucagon-Like Peptide-1 Agonists Among Individuals Undergoing Bariatric Surgery in the US. JAMA Surg. 2025 Oct 1;160(10):1058-1066. doi: 10.1001/jamasurg.2025.3089. PMID: 40864458; PMCID: PMC12392147.
